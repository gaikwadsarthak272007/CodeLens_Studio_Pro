# CodeLens Studio Pro 🔍⚡
> Interactive Data Structures & Algorithms (DSA) Visualizer built with Tailwind CSS and vanilla JavaScript.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-ready-brightgreen.svg)
![GitHub Pages](https://img.shields.io/badge/hosted-GitHub%20Pages-informational.svg)

CodeLens Studio Pro is an interactive web platform designed to help students, developers, and engineers visualize and master fundamental Data Structures and Algorithms with step-by-step execution, dynamic animations, and synchronized code line tracking.

---

## ✨ Features

- 📊 **Multiple Data Structures Supported:**
  - **Arrays**: Linear search, binary search, sorting visualizer, and custom modifications.
  - **Stack (LIFO)**: Push, Pop, Peek operations with stack boundary and pointer visualizers.
  - **Queue (FIFO)**: Enqueue, Dequeue, Front, and Rear pointer animations.
  - **Linked List**: Node traversal, insertion at head/tail, and deletion with pointer rewiring.
  - **Binary Trees**: Traversal (Pre-order, In-order, Post-order, Level-order) and node lookups.

- ⏯️ **Interactive Execution & Playback Controls:**
  - Play, Pause, Step Forward, and Step Backward controls.
  - Dynamic playback speed adjustment.
  - Synchronized pseudocode / code line highlighting matching each visual step.

- 🎨 **Modern Dark Glassmorphism UI:**
  - Responsive canvas stage with auto-scrolling viewports.
  - Real-time status cards showing time complexity, current variable values, and execution logs.
  - Zero external build dependencies — runs natively in any modern browser!

## 💻 Local Quickstart

No Node.js or build steps required! Simply:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/gaikwadsarthak272007/CodeLens_Studio_Pro.git
   cd CodeLens_Studio_Pro
   ```

2. Open `index.html` directly in your browser:
   - Double click `index.html`, OR
   - Run a lightweight local server:
     ```bash
     # Python 3
     python -m http.server 8000
     ```
     Then open `http://localhost:8000`.

## 🌐 Deploy to GitHub Pages (Step-by-Step)

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/<YOUR-REPO-NAME>.git
   git branch -M main
   git push -u origin main
   ```

2. Enable GitHub Pages:
   - Navigate to your repository on GitHub.
   - Go to **Settings** > **Pages** (under the "Code and automation" section).
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
   - Within 1–2 minutes, GitHub will generate your live URL!
