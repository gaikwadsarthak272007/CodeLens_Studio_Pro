# CodeLens Complete DSA Academy 🔍⚡
> Interactive Data Structures & Algorithms (DSA) Learning & Visualization Platform.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-ready-brightgreen.svg)
![GitHub Pages](https://img.shields.io/badge/hosted-GitHub%20Pages-informational.svg)

**CodeLens Complete DSA Academy** is a comprehensive, interactive EdTech platform designed to help students, developers, and engineers master fundamental Data Structures and Algorithms through guided curriculum paths, step-by-step interactive execution, and dedicated hands-on visualization laboratories.

---

## ✨ Features & Highlights

- 🎓 **Guided Learning Curriculum:**
  - **Module-by-Module Progression**: Theory, examples, and deep dives into core Computer Science fundamentals.
  - **Complexity Analysis**: Big-O runtime analysis, time/space trade-offs, and comparison matrices.
  - **Learning Path Tracker**: Structured learning flow spanning from fundamentals to advanced data structures.

- 📊 **Dedicated Interactive Visualization Labs:**
  - **Arrays**: 1D, 2D, and 3D indexing, linear search, binary search, and custom mutations.
  - **Stack (LIFO)**: Push, Pop, and Peek operations with visual pointer tracking and boundary checks.
  - **Queue (FIFO)**: Linear, circular, and priority queue animations with Front & Rear tracking.
  - **Linked Lists**: Singly, Doubly, and Circular Linked Lists with dynamic pointer rewiring.
  - **Trees & Binary Search Trees**: Tree generation and Pre-order, In-order, Post-order, and Level-order traversals.

- ⏯️ **Precision Execution & Frame-by-Frame Controls:**
  - Step Forward, Step Backward, Play, and Pause execution states.
  - Adjustable playback speed with real-time state inspection.
  - Synchronized pseudocode tracking highlighting active code lines at each execution step.

- 🎨 **Modern Dark Glassmorphism UI:**
  - Single-page application with zero external build dependencies.
  - High-performance SVG animations and responsive viewport layouts.

## 💻 Local Quickstart

No build tools or Node.js required! Simply:

1. Clone this repository:
   ```bash
   git clone https://github.com/gaikwadsarthak272007/CodeLens_Studio_Pro.git
   cd CodeLens_Studio_Pro
   ```

2. Open `index.html` directly in your browser:
   - Double-click `index.html`, OR
   - Run a lightweight local server:
     ```bash
     python -m http.server 8000
     ```
     Then navigate to `http://localhost:8000`.
