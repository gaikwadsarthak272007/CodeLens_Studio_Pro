Data, Information & Data Structure

Data: Raw, unorganized facts or atomic values (e.g., 42, 85, 19).
Information: Processed, structured data with context (e.g., Student Marks sorted highest to lowest).
Data Structure (DS): A systematic mathematical and logical way of organizing and storing data in computer memory so it can be retrieved and modified efficiently.

Fundamental Equation of Computing
Data Structure + Algorithm = Program
⚙️

Algorithm & Its 5 Properties

An Algorithm is a finite, step-by-step sequence of unambiguous instructions for solving a problem in a finite amount of time.

  • 1. Input: Zero or more externally supplied values.
  • 2. Output: Produces at least one result.
  • 3. Definiteness: Every step is clear and unambiguous.
  • 4. Finiteness: Must terminate after a finite number of steps.
  • 5. Effectiveness: Every operation is basic and feasible.
📦

Abstract Data Type (ADT)

An ADT is a logical mathematical model that defines what data is stored and which operations are supported (the interface), without specifying how they are implemented inside memory.

Contiguous Memory Allocation (Arrays)

O(1) Address Math

Elements are stored in unbroken, adjacent memory addresses. Knowing the Base Address (e.g., 0x2000) and element size (4 bytes), the CPU jumps directly to any index i in a single instruction:

Address(arr[i]) = Base_Address + (i × sizeof(Element))

          Core Efficiency Metrics
          
⚡ What are Time & Space Complexity?

        

        

          

            
1. Time Complexity — T(n)

            

              Measures the number of elementary CPU operations (comparisons, swaps, pointer steps, arithmetic) an algorithm performs as a function of the input size $N$, rather than raw wall-clock seconds (which depend on CPU hardware).
            

          

          

            
2. Space Complexity — S(n)

            

              Measures the total RAM memory required by an algorithm for an input of size $N$. It consists of:
              
• Input Space: Memory used to hold the input dataset itself.
              
• Auxiliary (Working) Space: Extra temporary variables ($O(1)$), clone arrays ($O(n)$ in Merge Sort), or Recursive Call Stack frames ($O(h)$ in Tree Traversals).
            

          

        

      


      
      

        

          Mathematical Bounds
          
📐 Asymptotic Notations Visualized ($O, \Omega, \Theta$)

        

        

          

            
Big-O — O(f(n))

            
Worst-Case Upper Bound

            

              Guarantees execution steps never exceed a multiple of $f(n)$. Example: Linear Search is $O(n)$ when the target is at the very end.
            

          


          

            
Big-Omega — Ω(f(n))

            
Best-Case Lower Bound

            

              Minimum operations required in the most favorable scenario. Example: Linear Search is $\Omega(1)$ when target is found at index `[0]`.
            

          


          

            
Big-Theta — Θ(f(n))

            
Average / Tight Bound

            

              When Upper and Lower bounds match asymptotically, $\Theta(f(n))$ locks the exact growth rate.
